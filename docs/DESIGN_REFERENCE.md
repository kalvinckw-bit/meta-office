## 從截圖確認的關鍵事實
1. **是 16-bit 像素風**，不是向量插畫。這是前兩版失敗的唯一原因。
2. **亮色系**：奶油／米色地板、薰衣草紫磚牆、飽和的紅綠傢俱。
3. **視訊格在畫面頂端橫排**，白框、左上名牌、右下綠色麥克風。
4. **名牌格式是 `名字@部門`**，深色小膠囊配白字。
5. **對話區是彩色圓地毯**，站上去即連線；MetaLife 還會在該區塊疊一層半透明色塊。
6. **角色很小**（約一格寬、一格半高），大頭、深色衣服。

## 本專案的取捨（見 DECISIONS.md 005）
- **沿用**：上述 1、3、4、5、6 的**操作邏輯與資訊架構** —— 屬於 Gather／oVice／ZEP／MetaLife 共通的品類慣例。
- **不沿用**：MetaLife 的實際美術資產、配色、商標。本專案所有像素圖形皆由 Canvas 程式自行繪製。
