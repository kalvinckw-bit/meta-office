# VoiceOut 訊號指揮室 —— AI 高管團隊

給 VoiceOut 社長 CK 的 AI 執行團隊。六位部長常駐在 Cowork 裡，隨時可以叫進來單獨談，或召開全體會議。

## 安裝

在 Cowork 裡打開這個 `.plugin` 檔案，按「安裝」。裝一次就好。

## 六位部長

| 指令 | 角色 | 負責 | 他的預設立場 |
|---|---|---|---|
| `/ceo` | 首席執行官 | 方向、取捨、優先順序 | 懷疑新功能 |
| `/cfo` | 首席財務官 | 現金、定價、VtP 負債 | 反對任何要先付錢的方案 |
| `/cto` | 首席技術官 | Firestore、地理查詢、安全 | 反對重構 |
| `/cmo` | 首席行銷官 | 冷啟動、密度、商家招募 | 反對付費廣告 |
| `/coo` | 首席營運官 | 流程、審核、自動化 | 反對建立流程 |
| `/advisor` | 首席顧問 | 假設、風險、第二意見 | 預設挑戰你 |

每位部長都有**明確的預設立場**，這是刻意的 —— 一群只會附和的顧問沒有價值。

## 全體會議

```
/board-meeting 我們下一季應該把力氣壓在單一校園的密度，還是先補商家端？
```

六位部長平行作答，然後彙整出：共識、**分歧**、最關鍵的一件事、兩週內的下一步、以及哪些答案其實是在猜。

## 叫人的兩種方式

用指令：`/cfo 訂閱要怎麼定價？`

或直接講話：「CFO 怎麼看這個定價？」 —— 描述裡的觸發語會自動叫出對應的部長。

## 業務背景

`context/voiceout-context.md` 是六位部長共用的 VoiceOut 背景（Signal Radar、VtPoint 經濟、商家端、Firebase 架構、以及社長目前的處境）。

**業務有變化時，改這個檔案就好** —— 六位部長會一起更新，不用一個一個改。

## 成本

零。不需要任何外部 API 或付費服務，跑在現有的 Claude 上。

## 指揮室介面

`metaoffice.html` —— 用瀏覽器打開就好，不需要伺服器。

MetaLife 式的 2D 虛擬辦公室，六位部長坐在各自的位子上：

- 方向鍵 / `WASD` 走動，**雙擊地板**瞬移
- 走近部長會**自動連線**，左下角跳出視訊泡泡，按 `E` 開始對話
- 中央玻璃會議室 = 全體會議，走進去七個人全部上線
- 右側成員一覽點名字可以直接走過去
- 底部工具列：回到入口 / 進會議室 / 表情反應 / 縮放
- 決策紀錄存在瀏覽器本機（localStorage），換電腦不會跟著走

視覺沿用 voiceout.asia 的設計 token：`#050505` 底、`#00E5FF` 主色、Orbitron、直角。
六位部長各用一個品牌色（CEO 青 / CFO 檸檬綠 / CTO 紫 / CMO 橘 / COO 金 / ADV 紅）。
